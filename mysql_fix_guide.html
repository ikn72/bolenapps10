🛠️ Panduan Mengatasi Error MySQL

Solusi lengkap untuk masalah MySQL di Windows dengan XAMPP

📊 Status MySQL Saat Ini

MySQL process tidak berjalan
Port 3306 tidak digunakan
XAMPP Control Panel sudah berjalan
1
🎯 SOLUSI TERMUDAH - XAMPP Control Panel
  • Buka XAMPP Control Panel (sudah terbuka)
  • Cari baris "MySQL"
  • Klik tombol "Start" di sebelah MySQL
  • Tunggu hingga status berubah menjadi "Running"
💡 Tips: Jika tombol Start tidak berfungsi, coba restart XAMPP Control Panel sebagai Administrator.
2
⚡ SOLUSI COMMAND LINE
  • Buka PowerShell sebagai Administrator
  • Jalankan salah satu command berikut:
net start mysql
Start-Service -Name "mysql"
3
🔧 SOLUSI DIRECT START
  • Buka Command Prompt
  • Jalankan command berikut:
C:\xampp\mysql\bin\mysqld.exe --console
⚠️ Perhatian: Window Command Prompt harus tetap terbuka selama MySQL berjalan.
4
🚨 MENGATASI ERROR UMUM
❌ Error: "Can't connect to MySQL server"
✅ Solusi: Start MySQL service (gunakan metode di atas)
❌ Error: "Access denied for user"
✅ Solusi: Periksa username/password
Default XAMPP: username = root, password = (kosong)
❌ Error: "Port 3306 already in use"
✅ Solusi: Matikan proses yang menggunakan port 3306
netstat -ano | findstr :3306
❌ Error: "MySQL service won't start"
✅ Solusi: Periksa file konfigurasi my.ini
Lokasi: C:\xampp\mysql\bin\my.ini
5
🧪 TEST KONEKSI MySQL
  • Setelah MySQL berjalan, test dengan command:
C:\xampp\mysql\bin\mysql.exe -u root -p
  • Tekan Enter saat diminta password (default kosong)
  • Jika berhasil, Anda akan masuk ke MySQL prompt
6
🌐 AKSES phpMyAdmin
  • Start Apache di XAMPP Control Panel
  • Buka browser dan kunjungi:
http://localhost/phpmyadmin

⚡ RINGKASAN SOLUSI CEPAT

1
Buka XAMPP Control Panel
2
Klik "Start" di MySQL
3
Tunggu status "Running"
4
Test koneksi
🔄 Refresh Status 🌐 Buka phpMyAdmin
